# Glasses UX Pitch — Agent & Docs Panels

## Current flow (keep it)
- The Agent page on the glasses shows a **master list** plus a **detail panel**.
- **Single tap** → move into the detail list.
- **Double tap** → back to the master list.
- This master/detail flow reads well and should be the pattern for both panels below.

## Change 1 — Add a full-screen level to both panels
Improve **both** the Agent detail panel and the Docs detail panel:
- Level 1 — master list only.
- Level 2 — single tap: master list + detail panel (as today).
- Level 3 — one more tap, using the ring: the detail takes over the whole view, the same way the currently focused Doc fills the screen today.
- Double Tap again → back to the master list with the detail panel.

## Change 2 — Agent page first on load
- Make the **Agent page the first page** shown when the app loads, instead of Docs.
